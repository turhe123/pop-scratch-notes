Features

Small panel, quick notes.

Everything sits between the clipboard and a full notes app, and nothing leaves your Mac.

Global hotkey toggle

Control-Option-Space shows or hides the panel from any app. You can record a different shortcut in Settings, and it warns you if another app already uses it.

Inline math results

End a line with = and the result appears in a muted color beside it. It handles + - * /, parentheses and decimals percent and units are not supported.

Up to 20 pages

Switch between numbered tabs with Command-1 to 9, add one with Command-T, and copy a whole page with one click.

Auto-save on every change

Pages are written to disk half a second after you stop typing, when the panel hides and when you quit. Escape hides the panel without losing anything.

Pin, resize, adjust

Pin a page to float above other windows, resize the panel, and set font size, monospaced text and opacity. It follows light and dark mode.

Offline and private

No account, no server and no network connections. Your notes live in a single JSON file on your Mac.

Install

Up and running in a minute.

PopScratchNotes is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download PopScratchNotes-macOS.zip and unzip it.
  2. Move PopScratchNotes.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/PopScratchNotes.app
  4. No special permissions are required if you enable Launch at login, macOS may ask you to approve it under System Settings General Login Items.

FAQ

Questions, answered.

Is PopScratchNotes really free and open source?

Yes. It is released under the MIT license, with no account, ads or paid tier. If it saves you time, there is an optional Support button that opens a Ko-fi page.

What permissions does it need?

None. The hotkey uses a system API that needs no Accessibility or Screen Recording access, and the app makes no network connections. Only the optional Launch at login setting may prompt you to approve it in Login Items.

Where is my data stored?

In a JSON file at ~/Library/Application Support/PopScratchNotes/pages.json on your Mac. If that file ever cannot be read, it is kept as a timestamped pages-corrupt copy and you start with a blank page.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account. Right-click the app and choose Open once to launch it, or build it yourself from source with Xcode.
